Chaque version publiée porte une étiquette `vX.Y.Z` dans le dépôt, avec son document OpenAPI joint. Avant de mettre à jour, lire la note de la version et suivre [Mise à jour](/docs/installer/mise-a-jour/).

| Version | Date | En bref |
|---|---|---|
| [Prochaine version](/docs/versions/prochaine/) | À venir | Volet recettes, courriels d'alerte, environnement de démonstration, cette documentation. |
| [0.1.0](/docs/versions/0-1-0/) | 16/11/2026 | Première version : chaîne de dépense complète, pilotage, intégrations, options d'interface. |
