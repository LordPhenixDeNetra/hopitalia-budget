La pharmacie saisit ses commandes et ses livraisons (approvisionnements) dans Hopitalia. Le module les importe chaque jour, **sans ressaisie**. L'agent financier rattache chaque commande à un engagement validé du même fournisseur.

## Rattacher une commande

1. Vue **À rattacher** : les commandes importées pas encore rattachées. Le **+** d'une ligne déplie ses produits.
2. Dans **Rattachement**, le module propose les engagements validés du même fournisseur dont le reste couvre la commande.
3. Choisir l'engagement, puis **Rattacher**.

Le rattachement crée le bon de commande dans le module. Les approvisionnements déjà livrés deviennent des **réceptions validées**, avec le bon de livraison pour preuve ; les suivants le deviennent à leur import.

« Aucun engagement validé du fournisseur ne couvre cette commande. » : il faut d'abord un engagement (voir [Engagements](/docs/utiliser/engagements/)).

La vue **Rattachées** liste les commandes déjà rattachées, avec le lien **Voir le bon de commande**.

## Quand Hopitalia change une livraison

| Changement dans Hopitalia | Effet dans le module |
|---|---|
| Approvisionnement modifié après sa réception | Une alerte « Écart de rapprochement » demande de vérifier la réception et la facture. |
| Approvisionnement supprimé | La réception est annulée (« Annulée (supprimée dans Hopitalia) ») et une alerte demande de vérifier les liquidations de la commande. |

Les imports se relancent sans créer de doublon (voir [Intégrations](/docs/administrer/integrations/)).
