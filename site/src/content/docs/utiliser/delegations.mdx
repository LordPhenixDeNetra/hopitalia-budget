Tout agent qui vise des pièces peut déléguer. Pendant la période, l'agent désigné vise à votre place, **avec vos profils**, dans les circuits de validation. Il n'obtient aucun autre droit.

<Capture nom="delegations" alt="L'écran Délégations : le formulaire avec le code agent du délégataire, les dates Du et Au, le motif et le bouton Déléguer, puis la liste des délégations avec leur état." />

1. **Code agent du délégataire** : son code Hopitalia, par exemple AG042.
2. **Du**, **Au** : la période.
3. **Motif**.
4. **Déléguer**.

La liste montre chaque délégation et son **État** : « À venir », « Active » ou « Terminée ». **Révoquer** y met fin tout de suite.

Un visa donné par délégation est marqué « par délégation de … » dans le circuit et dans le journal d'audit. La séparation des tâches s'applique au délégataire : il ne vise pas une pièce qu'il a saisie lui-même.
