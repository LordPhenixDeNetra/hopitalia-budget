## Attribuer un profil

**Attribuer un profil** :

1. **Code agent Hopitalia**, par exemple `AG042` : le module lit le nom de l'agent dans l'annuaire Hopitalia.
2. **Profil** : voir [Profils et droits](/docs/decouvrir/profils/).
3. **Établissement** : celui où le profil s'applique. « Tous les établissements » est réservé aux administrateurs globaux.

Un agent peut cumuler des profils ; la séparation des tâches s'applique quand même.

## Retirer un profil

**Retirer**, puis confirmer. Le retrait prend effet à la requête suivante de l'agent.

## Règles

- Un administrateur ne peut pas modifier ses propres profils : « Vos propres droits ne sont modifiables que par un autre administrateur. »
- Chaque attribution et chaque retrait sont tracés dans le journal d'audit.
- Un compte d'intégration (un autre système qui appelle l'API) reçoit ses profils de la même façon : le plus étroit qui suffit (voir [Authentification](/docs/integrer/authentification/)).
